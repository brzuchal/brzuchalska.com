# Zasoby graficzne

Ten katalog zawiera lokalne zasoby graficzne używane przez stronę.

- `logo-brzuchalska.svg` – logo w wersji wektorowej SVG.
- `symbol.svg` – sam sygnet/logo bez pełnego logotypu.
- `noBgWhite.png` – logotyp bez tła (biały), wykorzystywany w ciemnym nagłówku strony.
- `noBgBlack.png` – logotyp bez tła w wersji ciemnej.
- `noBgColor.png` – logotyp bez tła w kolorze firmowym.
- `with_padding.png` – wersja logo z dodatkowymi marginesami.
- `197419498.png` – alternatywny eksport logotypu.

## Identyfikacja wizualna

- Kolor podstawowy (tekst): `#111111` (RGB 17, 17, 17; CMYK 0%, 0%, 0%, 93%).
- Kolor akcentu: `#FFC93C` (RGB 255, 201, 60; CMYK 0%, 21%, 76%, 0%).
- Font logo (wordmark): `American Captain`.
- Font sloganu: `Syncopate Bold`.

Cel: uniezależnienie strony od zewnętrznego hostingu obrazów (np. poprzedni hosting Looka/AWS).
